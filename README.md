# The Truth

**The Truth**（确界）是一个 [Applied Energistics 2](https://github.com/AppliedEnergistics/Applied-Energistics-2) 的终局扩展模组，面向 Minecraft **1.21.1 / NeoForge 21.1.248** / AE2 **19.2.17**。

> 主世界的一切——方块、生物、物品、空间——都是确界的读出。
> 确界是 Minecraft 世界的存储层：未观测的区域是尚未写入的数据，覆盖是写入权限，
> 而未定形质，是还没被写进账本的内容。

## 世界观

确界（Certus）是 ME 文明破碎后的母世界。在这里，物质不稳定：离开网络覆盖的物品会
失去确切的形态（堆叠数量随机化、化为未定形质），深层区域的物质甚至会直接从账本上
被删除。只有让确定性覆盖（确界锚点 / 无线接入点）覆盖你作业的区域，这个世界的
"写入权限"才会承认你的存在。

四条设计红线：

1. **入口门槛位于 AE2 后期**（空间 IO + 成对纠缠奇点），不提供绕过路径。
2. **维度内物质不稳定**，必须建立确定性覆盖才能作业。
3. **地层必须经 ME 手段开采**（自动化是正解）。
4. **维度产物反向增强主世界 AE2 能力**。

**永不静默删除玩家物品**：一切损失都有前摇预警与可挽回窗口。

## 内容速查

| 内容 | 说明 |
| --- | --- |
| **确界维度**（`thetruth:certus`） | 三层结构：可教学的地表层、随机化的中间层、删除曲线的深层；观测周期驱动光/雾/天氛围 |
| **量子入口** | 确界门户；空间门槛需要 AE2 空间 IO 基建 + 成对纠缠奇点 |
| **确定性覆盖** | 确界锚点 / 脐带锚点投影 16 格覆盖球；覆盖时边缘呈现「写入扇区」的青色纬线圈 |
| **确界固化器** | 把带记忆的未定形质还原为原物品、游离未定形质固化为确界结晶；每次 200 AE；空手右键打开 GUI，手持未定形质右键直接插入 |
| **确界元件** | ME 存储元件（1,048,576 bytes / 256 types）；离网内容以组件形式永不丢失 |
| **残余物质簇 / 未定形质** | 中层矿簇挖出未定形质；未定形质恒定附魔光效并以数据流粒子呈现 |
| **残余 / 测量者 / 未观测者** | 三种确界生物；扫描可以被阴影与网格缺口规避 |
| **最后的测量者** | 三阶段 Boss；数据端口过载（AE2 import 抽取 16 份测量数据）是正解击杀路线；掉落确界核心与最后的记录 |
| **最后的记录** | 终局物品：把它**带回主世界**右键解读，一次性翻转整个世界（不可逆）；确界内拒绝解读 |
| **确界印记** | 终局之后，所有 ME 存储元件的图标右上角浮现小小的确界印记——只有经历过这一切的玩家才懂 |
| **脐带锚点** | 终局解锁后可在主世界与确界之间配对：跨维度的确定性覆盖 + 强制加载 |

## 常见问题

**物品数量为什么自己变了？**
你在未覆盖区域待过。确界的中间层会随机化堆叠数量并随机降解部分物品为未定形质；
回到覆盖下或在确界固化器还原即可。

**深层计时警告是什么？**
深层的删除曲线。警告窗口内建立覆盖可以挽救（数量恢复为记录值）；窗口耗尽后携带物
溶解为未定形质实体——它们永不消失，捡回来仍可还原。

**确界里的经验去哪了？**
经验在确界不会以经验球存在——它们凝为**数据残片**，右键读回。

**为什么 ME 驱动器拒收我的空间元件？**
空间元件不是 ME 网络存储（AE2 官方语义）；确界的印记与机制只承认 ME 存储。

## 安装

1. 安装 [NeoForge 21.1.248](https://neoforged.net/)；
2. 下载 [Applied Energistics 2 19.2.17](https://modrinth.com/mod/applied-energistics-2) 放入 `mods/`；
3. 下载本模组（见 [Releases](https://github.com/illagerCPR/the-truth/releases)）放入 `mods/`。

## 构建（开发者）

```bash
export JAVA_HOME=<JDK 21 路径>
./gradlew build          # 构建 jar
./gradlew runGameTestServer   # 无头机制测试（GameTest）
python3 tools/check_lang.py   # 语言键漂移检查
```

设计文档与批次记录见 `docs/`（简体中文）：`00-世界观创意方案.md`、`01-设计红线与技术闸门.md`、`02-开发计划.md`。
